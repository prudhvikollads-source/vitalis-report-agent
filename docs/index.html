Vitalis

A LangGraph multi-agent system that reads clinical lab reports — and knows when to say "I don't know."
⚠️ Case study of a software demo built on synthetic data (fictional patients). Not medical advice; not a medical device.

Problem

Pasting a lab report into a single LLM call produces confident prose that hallucinates reference ranges and never abstains. Measured on 24 synthetic reports: a naive baseline reported "normal" on 3 critically abnormal values (potassium 6.4 mmol/L) and answered 100% of adversarial reports. In health, the confident wrong answer is the failure mode that matters.

Solution

Five agents on LangGraph, each with one job: Ingest normalizes the report, Extractor pulls biomarkers, Skeptic independently recomputes every flag and challenges contradictions, Counselor drafts plain-language insights, Arbiter merges them into a cited answer — or abstains via three gates (missing units, critical contradiction, low extraction confidence). Flag math is rule-based in every mode; the LLM only writes prose from validated numbers.

Key decisions

LangGraph over LangChain chains — conditional routing (a failed report skips counseling) and per-node streaming, which the live demo visualizes.
Separate skeptic agent — the extractor transcribes what the lab printed, misprints included; only independent recomputation catches them.
Abstention as a product decision — exit code 2, three gates, measured rather than hoped-for.
Rule-based flag math, always — the model never invents a reference range, in mock or real mode.

Demo

The Streamlit app shows an animated agent floor: five avatars walk between desks as the pipeline runs, the skeptic fires challenges, and the arbiter delivers a cited answer — or the abstain banner. Fully offline; no API keys.
